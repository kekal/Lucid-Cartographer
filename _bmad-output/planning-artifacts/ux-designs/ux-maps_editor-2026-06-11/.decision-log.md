## Captured: New Trip View feature (from PRD, to design into spines)
- Trip View toggle in the filtered-results region; visible at ≥2 placeable POIs. Numbered stop badges, route legs (straight Phase 1 / road Phase 2 / great-circle Air), list↔map two-way selection sync.
- Per-leg travel time + **Fidelity badges** (Measured / Estimated / Placeholder / Manual); dashed connectors for non-Measured (assumption). Manual per-leg entry.
- Dwell time per stop + running arrival timeline; optional wall-clock start vs relative offsets (OQ6); optional time-budget overrun flag.
- Start/Finish/Roundtrip; ordering paths: manual drag, TSP-Sort button, MCP/AI assignment — all on-demand, never automatic.
- Trust counter-metrics: never false precision; collections must not feel forced into trips.
- Open questions to resolve: OQ4 (Placeholder vs "—"), OQ6 (timeline default), OQ8 (persistence scope), FR-6 dashed-line assumption.

## Resolved Trip View decisions (user, 2026-06-11)
- **OQ6 — Timeline default:** Both side by side — relative offset (e.g. "+2h15m") always shown; wall-clock time ("arrive 14:10") shown additionally when a trip start time exists.
- **OQ4 — Empty Air/Any leg:** Render the time as an em-dash "—" (quiet) rather than a Placeholder badge.
- **FR-6 — Non-Measured leg styling:** Dashed connector **and** a lighter/muted stroke; Measured road geometry is solid full-color. Reinforces the Fidelity badge.
- **OQ8 — Persistence:** Per-collection, persisted. Trip View on/off and stop order save with the collection and restore on reopen (matches UJ-1).

## Reviewer Gate (2026-06-11) — lenses: rubric, trust/honest-signaling, PRD fidelity
Results: 0 blockers. Rubric 5 minor; Trust 5 major + 4 minor; PRD fidelity 2 major + 6 minor. Reports: `review-rubric.md`, `review-trust.md`, `review-prd-fidelity.md`. Findings resolved before finalize:
- **Aggregate timeline honesty (Trust M1 / SM-C2):** a running total/arrival inherits the lowest fidelity it sums; shown qualified (`~18:10 · Estimated`), never a clean confident time. Added to DESIGN (timeline + Do/Don't) and EXPERIENCE (Mixed-fidelity total state). Flow 1 climax + voice example updated to match.
- **Line solidity = geometric fidelity (Trust M3):** only Measured renders solid; Estimated/Manual/Placeholder/Air all dashed+muted. Manual trust lives in the badge, not the line. DESIGN route-leg + Do/Don't; EXPERIENCE Fidelity-badge + Manual-entry rows.
- **Em-dash generalized (Trust M2):** any unmeasured/unentered leg (any mode) shows "—", not just Air/Any. DESIGN + EXPERIENCE.
- **FR-13 timeline rules (PRD majors):** unplaceable stop's dwell still accrues (no travel time); Start dwell counted once; roundtrip distinct return arrival. Added EXPERIENCE Itinerary-timeline component row + Unplaceable-stop-in-timeline state.
- **Recompute / Estimated→Measured upgrade (PRD FR-10/11):** added EXPERIENCE "Recompute travel times" component + provider-down recovery note.
- **Provider egress (Trust M4):** strengthened to a firm non-negotiable guard (consent before first out-call); only placement/copy deferred.
- **Time-budget field (Rubric M-4):** clarified as an optional settable per-trip field; overrun flag fires only when set.
- **Breakpoint token (Rubric M-1):** EXPERIENCE Foundation now uses `{components.desktop-breakpoint}`.
- **Keyboard reorder (Rubric M-2 / a11y):** retained as `[ASSUMPTION]`, marked build-blocking for a11y.
