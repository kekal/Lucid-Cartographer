## Lessons / Action Items

- **B1 — Shared-layer fixes reach mobile by nature; run the mobile suite to prove it.** 2.1/2.2
  changed `ItineraryTimeline`/`TravelTimeFormatting`/`UiStrings` — code mobile runs. Running the
  mobile filter (53 tests) each time confirmed no per-surface drift (NFR5). Keep doing it for any
  shared-layer change.
- **B2 — Round-once must use ONE rounding edge for BOTH per-leg display and accumulation.**
  `Duration(Σ seconds) ≠ Σ Duration(legSeconds)` even with round-half-up. The fix was a single
  `DisplayMinutes` helper used by both the per-leg formatter and the timeline accumulation, plus a
  total computed as `Σ DisplayMinutes(leg)` (not `round(Σ seconds)`). The reconciliation invariant
  test (90+90 → 4 min, not 3) is the guard.
- **B3 — Unit/string changes ripple widely; build-then-run to enumerate the assertions.** The "min"
  change broke 10 test assertions across 5 files. Building then running the fast suite pinpointed
  every one; each was updated faithfully (recomputed from the new rule, never weakened).
- **B4 — Key provider-state on the CONFIGURED provider, not per-leg.** 2.4's `RecommendsOsrm`
  checks `travelTimeProvider.Source != Osrm` (the deployment) AND a non-fallback Estimated leg
  exists — and stays mutually exclusive with the fallback note (fallback wins on a mixed trip).
- **B5 (reinforces Epic-1 A1) — a11y needs review attention; persistent vs transient matters.**
  2.4's recommendation note was first a `role=status` aria-live region — wrong for a *persistent*
  hint (re-announces on re-render). Fixed to normal document flow; the *transient* engine-
  unreachable note keeps its live region. The adversarial review caught it. Rule: live regions are
  for state CHANGES, not standing context.
- **B6 — Mix inline vs delegated work by size.** Trivial mechanical changes (2.2 strings, 2.5
  title parity) were done inline by the orchestrator with focused self-review; the substantive
  arithmetic/UX/logic stories (2.1, 2.3, 2.4) went to fresh subagents + fresh-context adversarial
  review. Both paths kept the suite green and stayed honest.
