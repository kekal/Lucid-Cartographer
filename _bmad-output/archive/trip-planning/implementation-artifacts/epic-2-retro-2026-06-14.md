## What went well

- **Per-story fresh-context adversarial review earned its keep every single time.** It caught a boot-level DI crash (2.1), an AC4 honesty bug (2.2), an untested defensive guard (2.3), and a compact-row precision gap (2.6) — none of which the (green) unit suite surfaced on its own.
- **Reuse over reinvention.** Every story leaned on existing infra: `GeoUtils.HaversineDistance`, the `PoiEnrichmentBackgroundService` pattern, the shared `SqliteWriteLock`, the `RouteSegment` cache + string-enum/check-constraint precedent. Result: **zero new migrations** across the whole epic.
- **Good design made honesty testable.** Pulling the timeline into a pure `ItineraryTimeline.Compute` (2.6) let the aggregate-honesty rule be proven exhaustively with plain unit tests — the epic's whole point ("never fake precision") is locked down by assertions, not hope.
- **Free invariants from prior design.** The directional cache key `(From,To,Mode)` + the `IsAnyLegComputing`-gated trigger gave "no-op reorder ⇒ no recompute" (FR-11/SM-C2) with no new code — only a test.

## Challenges & recurring patterns (the lessons)

1. **The unit suite is blind to host boot + DI wiring.** The single biggest bug of the epic (2.1: the hosted travel-time service crashed the integration host because `IntegrationTestBase` composes services by hand and never registers the Polly pipeline) was invisible to 589 green unit tests and only caught by running **Trip integration**. The same class of risk recurred in 2.4 (VM + `PoiService` ctor changes). → **Lesson A3 below.**
2. **Stop-row layout is a selection minefield.** A row element over the clickable center either intercepts a `stopPropagation` input (2.2 manual-time suffix span) or collapses the `flex-1 truncate` name span (2.5 dwell `w-12`→`w-10`; 2.6 arrival value). Recurred in 2.2, 2.5, 2.6. → **Lesson A4 below.**
3. **Honesty bugs hide behind shallow tests.** 2.2's computed-Placeholder-leg-shows-a-real-time and 2.6's estimated-offset-without-a-`~` both passed initially because tests used *uncomputed/null* legs or asserted the *badge* instead of the rendered *value*. → Test the **computed** path and assert the **displayed value**, not that a method ran or a badge exists.
4. **Defensive guards rot if unreachable.** 2.3's Manual/Measured no-downgrade guard was a no-op pass until `UpsertAsync` was made `internal` and driven directly. → If a guard is only reachable by a future story's path, expose it and test it now.
5. **Spec vs. reality needs reconciling at story-creation time.** Several PRD/architecture details didn't match the shipped code: cache key with Provider (FR-11) vs. the 3-part key (AR-1); non-existent tokens (`on-surface-muted`, `warn`); Any/Air→Estimated (FR-10) vs. →Placeholder (AR-10). Each was pinned in the story's Dev Notes so the dev didn't guess — that reconciliation step is load-bearing.
