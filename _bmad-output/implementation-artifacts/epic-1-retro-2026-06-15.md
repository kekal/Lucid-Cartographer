## Lessons / Action Items

- **A1 — The adversarial review earns its keep on a11y.** Story 1.3 shipped (from the dev)
  with the leg connector wrapped in `<li aria-hidden="true">`, which trapped focusable
  controls + meaningful info outside the accessibility tree (NFR7 violation). Root cause: the
  **story spec itself** gave conflicting guidance (`aria-hidden` wrapper *and* a labeled
  focusable reset button). The fresh-context reviewer flagged it HIGH; fixed before commit.
  *Standing rule:* never wrap focusable/meaningful content in `aria-hidden`; mark only
  decorative glyphs. Watch for self-contradicting story instructions.
- **A2 — `MapPage` cannot be rendered in bUnit** (`@rendermode InteractiveServer` +
  `LeafletMap.WaitForInitAsync()` TCS that only completes from JS interop → the render hangs).
  *Standing pattern:* prove page-level branch logic with a faithful bUnit render-fragment
  proxy AND back it with the Playwright Trip integration suite (which drives the real page).
  Document the proxy limitation in the test.
- **A3 — Interim-then-extract decomposition worked.** 1.2 rendered per-leg info as an interim
  inter-row line; 1.3 extracted it into the real `LegConnector`. Each story stayed shippable
  and the seam was clean. Reuse this for UI built across consecutive stories.
- **A4 (carried, held) — Run the Trip integration filter after any VM/projection change.**
  Every Epic 1 story touched the VM/projection or the page; the filter stayed green (20/20)
  throughout and caught nothing regressing — because we ran it each time.
- **A5 — Test re-alignment vs test-weakening.** Story 1.1 had to re-point integration
  selectors (PoiTable badges → takeover-panel badges) because the underlying surface changed.
  The reviewer verified each edit re-expressed the SAME guarantee (and 1.1 actually
  *strengthened* coverage with "PoiTable absent during takeover"). *Standing rule:* when a
  story changes a surface, integration-test edits are expected — the reviewer must confirm
  they preserve (not relax) the guarantee.
