## What went well

1. **The single-write-path architectural bet paid off.** AR-11 (every `OrderIndex` write through one `TripOrderingService` method) held across all 7 stories. Stories 1.5 (reorder) and 1.7 (pin) *extended* the seam rather than forking it — exactly the design 1.2 set up. The epic's biggest structural win.
2. **Adversarial 3-layer review (Blind Hunter + Edge Case Hunter + Acceptance Auditor) caught real bugs every story.** Concrete saves: 1.1 `OrderIndex` backfill orphaning rows via inner JOIN; 1.2 viewport-flip badge drop + non-placeable backfill numbering; 1.3 undefined `--outline` CSS var stranding a hardcoded hex; 1.7 orphaned Start/Finish pin reconciliation. The recurring `marker._poiId` false positive was correctly dismissed each time.
3. **Deferral tracking functioned as designed memory.** 1.3 logged "closing leg targets `stops[0]`, not `StartPoiId` — resolve when 1.7 lands"; 1.7 landed and fixed exactly that via `TRIP-STARTFINISH-07` `ReconcileOrderAsync`.
4. **Discipline never slipped** — warnings-as-errors, zero group-B analyzer violations, `TRIP-*` greppable comment codes, dual desktop/mobile render paths, and 3-layer (unit/bUnit/integration) testing applied consistently.
5. **Schema done once.** 1.1 shipped the full trip schema + `RouteSegment` cache up front; no later story needed a second migration. Epic 2 inherits a ready cache table and a centralized `IsPlaceable` predicate (1.6).

## Challenges & recurring patterns

1. **The same defer keeps returning: "Trip View stuck-on below the ≥2 placeable gate."** Logged in 1.3, re-surfaced in 1.4, logged again in 1.7. Three appearances, unresolved — overlays remain with no control to disable Trip View when placeable count drops below 2 (and at exactly 1 placeable stop the Set-as-Start/Finish controls stay live on a legless trip).
2. **Write-path atomicity deferred three times (1.2, 1.5, 1.7).** Read-validate-write is not a single transaction; only `SaveChangesAsync` is under `SqliteWriteLock`. Low risk today (single-user, serialized Blazor circuit, `PoiCollection.Version` token) — but every defer says "revisit when concurrent writers arrive."
3. **Integration harness can't exercise Leaflet.** `StubMapService` no-ops map interop, so marker badges, popup/tooltip non-regression, and dashed-leg styling are verified by inspection only (deferred in 1.2, 1.3, 1.4). A standing coverage gap, not a one-off.
4. **Minor flakes under parallel load** — `ScrapeProgress_ShowsIndicator` and `Union_ShowsAllUniquePois`. Pre-existing, pass in isolation, not regressions.
