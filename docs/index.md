Refreshed 2026-06-20 (as-built baseline) with two more Trip-View changes: the **Trip View toggle now gates on collection membership (≥1 placeable POI), not the map viewport** (commit a6114bd — panning away no longer hides it; `MapPageViewModel.CollectionPlaceablePoiCount` + a single `MinPlaceableForToggle` threshold), and a **Bulk Travel Mode** selector (`BulkLegModeSelector`, TRIP-BULKMODE-01, commit 523043e) that assigns one mode to **all** legs in one gated transaction, with an overwrite-existing checkbox — the remedy for an all-Any/Air trip whose Sort/Recompute stay disabled. No schema/endpoint/infra change in this delta. Refreshed 2026-06-24 (as-built baseline) with the **measured travel-times** feature (3 epics; commit 451a0ec): the default estimate is now a **smart-haversine** (great-circle distance scaled by per-mode detour factors — Drive 1.3 / Cycle 1.2 / Walk 1.15) computed in-process by the `MockTravelTimeProvider`; the **hand-rolled OSRM provider was removed entirely** and replaced by a single self-hosted **Valhalla** measured-routing provider (`docker-valhalla`, opt-in via `TravelTime:Provider=Valhalla`, one engine serving all ground modes via dynamic costing, polyline6 geometry). A retired/unknown `TravelTime:Provider` (including `Osrm`) no longer fails startup — it warns prominently and falls back to the smart-haversine default; a one-time startup step purges legacy `Source="OSRM"` cache rows. NFR7 privacy is a hard guarantee (Valhalla self-hosted; stop coordinates never egress; only outbound is the build-time region `.pbf` fetch — verified by `NoEgressTests`). No schema/migration change (still 13 app migrations). This is the primary entry point for AI-assisted development._

## Project Overview

- **Type:** Monolith (single .NET solution: app + test project)
- **Classification:** `web` — full-stack Blazor Server
- **Primary language:** C# / .NET 8 (C# 14 LangVersion → .NET 10 SDK to build)
- **Architecture:** Components → ViewModels → Services (vertical slices) → Data (EF Core / SQLite)

## Quick Reference

- **Tech stack:** Blazor Server, EF Core + SQLite, Tailwind 3.4.17, Coravel, Polly, Playwright, OpenIddict (OAuth 2.1), ModelContextProtocol.AspNetCore, optional self-hosted Valhalla (Trip measured routing; default is in-process smart-haversine)
- **Entry points:** `LucidCartographer/Program.cs` (composition root), `Services/StartupCleanupService.cs` (one-shot startup)
- **Run:** `dotnet run --project LucidCartographer` or `docker-compose up`
- **Test:** `dotnet test`

## Getting Started

1. Install the **.NET 10 SDK** (required even though the app targets net8.0).
2. `dotnet build` (auto-downloads the Tailwind CLI; no Node needed).
3. `dotnet run --project LucidCartographer` — grab the seeded admin password from the first-run log.
4. Read [architecture.md](./architecture.md) and [../_bmad-output/project-context.md](../_bmad-output/project-context.md) before changing code.
