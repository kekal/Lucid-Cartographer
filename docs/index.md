## Project Overview

- **Type:** Monolith (single .NET solution: app + test project)
- **Classification:** `web` — full-stack Blazor Server
- **Primary language:** C# / .NET 8 (C# 14 LangVersion → .NET 10 SDK to build)
- **Architecture:** Components → ViewModels → Services (vertical slices) → Data (EF Core / SQLite)

## Quick Reference

- **Tech stack:** Blazor Server, EF Core + SQLite, Tailwind 3.4.17, Coravel, Polly, Playwright, OpenIddict (OAuth 2.1), ModelContextProtocol.AspNetCore, optional OSRM (Trip routing)
- **Entry points:** `LucidCartographer/Program.cs` (composition root), `Services/StartupCleanupService.cs` (one-shot startup)
- **Run:** `dotnet run --project LucidCartographer` or `docker-compose up`
- **Test:** `dotnet test`

## Getting Started

1. Install the **.NET 10 SDK** (required even though the app targets net8.0).
2. `dotnet build` (auto-downloads the Tailwind CLI; no Node needed).
3. `dotnet run --project LucidCartographer` — grab the seeded admin password from the first-run log.
4. Read [architecture.md](./architecture.md) and [../_bmad-output/project-context.md](../_bmad-output/project-context.md) before changing code.
