# Project Rules

## Code changes
- Keep changes minimal. Touch only what the task requires.

## Comments
- Keep comments short and to the point.
- Don't write comments that narrate the current task.
- Comment only where the location is unusual or relies on a non-obvious convention.
- Keep method and class descriptions concise.

## tmux 
- Cygwin tmux is not usable for agent automation. Use subagents instead.
